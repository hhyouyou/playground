# 共享 3D 素材

广场级的共享素材库：可被多个 idea 复用的 3D 模型、程序化生成脚本与预览图。

**这里不是 idea**，不进根目录的 idea 索引。素材服务于多个项目，所以单独放在广场层。

## 目录

| 目录 | 内容 |
| --- | --- |
| `farmhouse-courtyard/` | 农家庭院场景：一个 `.glb` 模型 + 生成脚本 + 校验脚本 + 预览图 |

## 单个素材的约定

每个模型一个子目录，三样东西必须齐全，保证**可复现**：

| 文件 | 作用 |
| --- | --- |
| 产物（`.glb` / `.gltf`） | 直接被项目引用的模型 |
| 生成脚本（`generate.py` 等） | 能重新生成产物，改参数不用手工建模 |
| 预览图（`preview.png`） | 不开 3D 软件也能确认长什么样 |

建议再加一个校验脚本（如 `validate.py`），检查面数、尺寸、材质和坐标轴朝向是否符合预期——模型出问题通常很隐蔽。

## 引用方式

项目通过相对路径引用素材，例如：

```js
loader.load('../../models/farmhouse-courtyard/farmhouse-courtyard.glb')
```

但注意：idea 目录必须能**脱离广场独立运行**。如果某个项目长期依赖这里的素材，毕业时要把对应素材复制到新仓库，或者在 README 里写明来源。

## 大文件

- 单个文件超过 50 MB 不要直接提交，优先考虑 Git LFS 或外部存储。
- 需要外部来源时，在对应子目录的 README 里写清来源、许可证和版本。
- 生成脚本永远比产物重要：产物可以重新生成，脚本丢了就得重做。
