# 黄金矿工 · Gold Rush

一个无需后端、可直接在浏览器游玩的经典黄金矿工小游戏。使用原生 JavaScript 与 Canvas 绘制，所有游戏美术均由代码生成。

## 启动

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址。生产构建：`pnpm build`，构建结果在 `dist/`。

## 操作

- **单人**：空格 / S / ↓ / 点击矿区放钩，X / ↑ 炸药，T 沙漏
- **双人 P1**：S / 空格放钩，X 炸药，T 沙漏
- **双人 P2**：↓ 放钩，↑ 炸药，Enter 沙漏
- **P / Esc**：暂停或继续；**M**：开关音效
- 手机端可使用各自玩家的触控按钮；双人也可分别点击矿区左右半边
- **表情互动**：P1 按 1 / 2 / 3，P2 按 7 / 8 / 9，分别挥手、指向宝物、点赞；也可点击矿区上方的表情按钮

## 角色与视觉状态

开局采用独立的四步“出征准备”场景页：组建队伍 → 选择任务 → 选择矿工 → 选择目标矿区。每步都有实时模型预览、特色说明和数值倾向，不使用遮罩表单。角色选择支持 P1/P2 独立配置，也可以点击场景里的矿工换装。

任务会真实改变关卡内容和计分：黄金勘探为均衡规则；宝石追踪让钻石与金猪价值提高 10%、团队目标提高 5%，并加入额外钻石；爆破开采加入额外 TNT、岩石加价 $25、团队目标降低 5%。不同任务、人数和难度分别保存最高纪录。

角色使用 Canvas 分层部件与关节动画绘制，具有呼吸、眨眼、曲柄摇臂、后坐发力、流汗、庆祝和失落等状态；轻、中、重、超重四档回收表现不同。

| 角色 | 外观 | 轻量被动 |
| --- | --- | --- |
| 老乔 | 白胡须、经典宽檐帽 | 无，保持标准操作手感 |
| 阿岩 | 魁梧体型、深色装束 | 重物回收 +8%，摆钩速度为 95% |
| 莉莉 | 护目镜、马尾、轻便装备 | 钻石与金猪回收 +6% |
| 洛克 | 红头巾、爆破工具腰带 | 初始炸药 +1，摆钩速度为 95% |

黄金与钻石有高光，岩石与骨骸回收时掉碎屑，福袋会摇晃，金猪被抓住后挣扎，TNT 引信会闪烁。钩爪命中后闭合，绳索随重量振动，卸货时矿车弹跳。所有视觉惯性、后滑和表情只影响绘制，不改变碰撞、回收数值和双人计分。

玩法说明中可开启“减少角色动画与镜头震动”，减少呼吸、摆动、闪烁和震动表现。

## 双人协作模式

出征准备页选择“双人协作”后，两位玩家各有一只独立钩爪，可以同时出钩、抓取不同矿物。双方共享矿区、倒计时与过关目标，个人成绩相加形成团队成绩；同一矿物只能被一位玩家认领并计分一次。

金币、炸药、沙漏、一次性增益和商店货架均按玩家独立计算。任一方使用沙漏会为双方增加共享时间。倒计时结束后会等待双方钩爪都收回、奖励全部入账，再统一进入商店或结算失败。单人和双人分别保存各难度最高纪录。

## 难度

| 难度 | 目标 | 时间 | 其他变化 |
| --- | --- | --- | --- |
| 轻松 | 标准目标的 80% | 标准时间的 125% | 摆钩较慢、回收更快、岩石更少 |
| 经典 | 标准目标 | 标准时间 | 经典节奏 |
| 困难 | 标准目标的 120% | 标准时间的 85% | 摆钩更快、回收更慢、障碍更多 |

三种难度分别保存最高纪录。钩爪摆动范围约为 77°，所有可收集物及其移动轨迹都限制在带安全余量的可达扇区内；不可达的浅层边角会有意留空。

## 关卡与矿物

倒计时结算时累计成绩达到本关目标即可进入商店。关卡依次循环荒漠矿区、水晶洞窟、古老遗迹和熔岩矿脉主题；第 2 关开始出现钻石金猪，第 3 关开始加入骨骸和 TNT。双人矿区按两个钩爪原点的可达区域并集生成。

| 矿物 | 价值 | 特性 |
| --- | --- | --- |
| 小黄金 | $50 | 较轻 |
| 中黄金 | $100 | 中等重量 |
| 大黄金 | $250 | 较重 |
| 巨型黄金 | $500 | 很重 |
| 钻石 | $600 | 非常轻 |
| 岩石 | $20 | 沉重，建议使用炸药 |
| 神秘福袋 | 随机 | 金币、炸药或额外时间 |
| 钻石金猪 | $700 | 在可达轨迹内来回移动 |
| 古老骨骸 | $15 | 沉重障碍物 |
| TNT | 无 | 触碰后爆炸，摧毁附近矿物 |

## 随机关卡商店

过关后每位玩家随机上架三件商品。双人可切换 P1/P2 货架，售出状态和背包互不影响。消费使用“可用金币”，不会扣减用于过关的“累计成绩”，未消费金币会保留到后续关卡。

| 商品 | 价格 | 效果 |
| --- | --- | --- |
| 高爆炸药 | $110 | 增加一个炸药，主动使用，库存上限 5 |
| 时光沙漏 | $100 | 增加一个沙漏，按 T 增加 12 秒，库存上限 3 |
| 大力饮料 | $180 | 下一关重物回收速度提高 55% |
| 幸运四叶草 | $160 | 下一关福袋更容易开出高额金币 |
| 钻石鉴定书 | $220 | 下一关钻石价值提高 50% |
| 岩石收购书 | $140 | 下一关岩石价值提高到 $100 |

一次性增益只在下一关生效；每偶数关还会补充一个炸药（不超过库存上限）。
