# 家庭维护助手（Home Maintenance）

一个用于记录家庭设备与家务维护周期、展示待办状态，并在未来接入智能家居事件的轻量项目。

## 当前状态

当前包含加湿器维护原型和 **DSH 插件第一版**：

- 已确定亮色、薄荷绿、圆润卡片的家居视觉方向。
- 已制作维护状态卡片、剩余天数、进度条和维护日历的组合视觉稿。
- DSH 插件提供左侧「家庭维护」入口、真实完成记录、自定义周期任务和可交互维护日历。
- 原始功能页保留用于参考和回归验证。
- 数据保存在浏览器本机，无需账号，也不需要构建工具。

> 视觉预览页使用演示数据；智能家居接入、通用任务编辑和主动通知尚未实现。

- [dsh-plugin](dsh-plugin/)：DSH 插件包，当前版本 `1.0.1`，包名 `@local/dsh-home-maintenance`。安装后在左侧选择「家庭维护」。当前安装操作已返回 `applied`；实际显示、主题切换和运行交互仍需在 DSH 页面中人工确认。
- [humidifier-design-preview.html](humidifier-design-preview.html)：最新视觉预览。方案一已融合维护日历，支持翻月、选择日期和查看当天安排。
- [humidifier-maintenance.html](humidifier-maintenance.html)：最初的可记录功能页，保留用于参考和回归验证。
- [humidifier-style-home-calendar.png](humidifier-style-home-calendar.png)：当前选定的家居卡片与日历组合效果图。
- `humidifier-style-*.png`：其他视觉方案的过程稿。

## 产品方向

### 1. 通用周期任务

将“滤芯每 7 天清洁、每 180 天更换”的逻辑抽象为通用任务，不只服务于加湿器。

可支持的家庭任务示例：

- 扫地、拖地：每若干天一次，或每周指定星期。
- 整理冰箱：每若干天一次，记录过期食品检查。
- 清理油烟机：按月或按使用频率提醒。
- 清洗洗衣机：按周期提醒，并记录最近一次清洗。
- 其他设备：空调滤网、空气净化器滤芯、热水器、饮水机等。

后续可逐步支持：

- 每 N 天、每周指定日期、每月指定日期等周期规则。
- 自定义任务名称、分类、图标、提醒周期和提前提醒时间。
- 完成后自动计算下一次日期，并保留历史记录。
- 按房间、设备或家务类型分组。
- 日历视图、列表视图和今日待办视图。

### 2. 触发型任务

除了固定周期，还可以由家庭事件触发任务，例如：

- 空气质量变差时，提醒检查空气净化器或通风。
- 湿度持续异常时，提醒检查加湿器或除湿设备。
- 设备累计运行达到阈值时，提醒清洁或更换耗材。
- 水位不足、设备离线、传感器异常时生成待处理事项。
- 冰箱门长时间未关闭、洗衣机程序结束等事件触发通知。

### 3. 智能家居消息汇总与动作

未来的事件处理链路可以拆成四层：

1. **来源适配**：接收智能家居平台、传感器、Webhook 或本地消息。
2. **统一事件格式**：记录来源、设备、事件类型、数值、单位、发生时间和原始内容。
3. **规则判断**：按阈值、持续时间、重复次数或组合条件触发任务；包含去重、冷却时间和规则开关。
4. **动作执行**：生成维护待办、发送通知、汇总日报，或在用户授权后调用设备动作。

涉及设备控制时，应提供明确权限、操作确认和审计记录，避免传感器误报直接造成危险动作。

## 建议演进顺序

1. 在运行中的 DSH 页面验证组合视觉、完成记录和日历交互。
2. 完善通用任务数据结构，增加暂停、任务模板和更多周期规则。
3. 增加提醒设置、导入导出和本地备份。
4. 再接入智能家居只读事件，先实现消息汇总与提醒。
5. 最后评估需要授权的自动化设备动作。

## 设计原则

- 默认使用当前选定的清新家居亮色风格。
- 优先让用户一眼看清“今天需要做什么”。
- 周期任务与触发任务使用统一的完成记录和日历视图。
- 能本地完成的功能优先本地实现；外部平台连接作为可选扩展。
- 在通用化之前保持数据结构简单，避免过早搭建复杂平台。
