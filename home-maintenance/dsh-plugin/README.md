# Home maintenance

A local-first household maintenance tool page for DeepSeek Harness.

## Usage

Open **家庭维护 / Home maintenance** in the left sidebar. The page includes:

- Four humidifier maintenance templates: filter cleaning, tank and body cleaning, pump descaling, and filter replacement.
- One-click completion records and editable reminder intervals and last-completion dates.
- Custom recurring cleaning or replacement tasks; custom tasks can be deleted, while the four built-in templates remain available.
- Short-term undo after completion records.
- A monthly calendar with completion records, persistent overdue tasks, upcoming maintenance, date details, and keyboard navigation.

All task data is stored in the current browser's local storage. Clearing site data removes the records. This version does not send data to a server, run background notifications, connect to smart-home platforms, or control devices.

Disabling or removing the bundle removes the sidebar entry and page. Existing browser-local records are not deleted by disabling the bundle.
