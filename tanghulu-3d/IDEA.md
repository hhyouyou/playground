# IDEA · 奶皮子糖葫芦 3D 展示

| 字段 | 内容 |
| --- | --- |
| 目录 | `tanghulu-3d/` |
| 状态 | 🧪 验证中 |
| 开始日期 | 2026-11-17 |
| 最近更新 | 2026-11-18 |
| 一句话 | 给食品品牌做能旋转、能拆解、能逐层认识配料的 3D 展示页，比图片和视频更能让人记住这东西好吃在哪 |
| 目标用户 | ① 想在网上把产品拍得诱人的小型食品品牌（糖葫芦、甜品、茶饮）；② 逛到页面、但还没决定要不要买的人 |
| 它解决的问题 | 电商详情页只能靠图片和视频讲「层次感」，用户看不出食材结构和用料，也没法按自己的兴趣看细节 |
| 关键假设 | ① 3D 拆解 + 标注能真实提升「看了就想买」的感觉，而不只是炫技；② 这件事可以模板化——换模型就能复用到别的食品，所以值得做成产品而不是一次性作品；③ 移动端能跑得动（加载时长、帧率可接受） |
| 验证方式 | 把页面发给 3–5 个潜在需求方（做食品/电商的朋友）看，观察他们是「哇」还是「然后呢」；追问一句：愿不愿意为这样的展示页付钱或用在自己的商品上 |
| 毕业线 | ① 至少 1 个真实品牌愿意把它用在商品页上（哪怕免费试点）；② 有人主动问「能不能给我也做一个」；③ 手机端首屏 3 秒内可交互、交互过程不掉帧到卡顿 |
| 放弃条件 | 反馈集中在「好看但没用」或「手机太卡」，且已尝试过简化模型仍无改善 |
| 当前进度 | Three.js 单页展示：奶油糖衣、草莓（宽头朝下建模）、奶皮子薄片、竹签、陶瓷底座；支持拖动旋转、双指缩放、自动旋转、拆解、标注、导出 PNG；Vite 构建通过，Chrome/WebGL 实际渲染与交互已验证，控制台 0 错误 |
| 下一步 | 拿给潜在需求方看，问「你会把它用在哪个商品页上」——用一个真实意愿来判断它是作品还是产品 |
| 结论记录 | 尚无需求侧验证记录 |

## 备注

- 技术侧已经验证完（能渲染、能交互），**剩下要验证的只有需求**。这个卡最该花时间的地方是找人看，不是继续调材质。
- 真正的产品形态大概率不是「这一个糖葫芦」，而是一套**换模型就能用的食品展示模板**；如果在验证中得到支持，下一步应该先抽象出模板，再做第二个案例。
- 如果结论只是「漂亮的作品集展示件」，那就归档成展示件，别再往里投时间。
